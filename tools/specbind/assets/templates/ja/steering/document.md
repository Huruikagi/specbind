# 表題

<!-- specbind:instruction create
これは主題を著者が選ぶ steering 文書のための雛形である。他のすべての SpecBind テンプレートと
異なり artifact_id を宣言していない。steering の識別子は著者が選ぶものだからである。書き始める
前に、既存のどの steering 文書とも重複しない小文字ケバブケースの識別子を決める。この文書は、
`template list steering` が報告した project_path の <artifact_id> をその識別子に置換した場所だけに
作成する。

見出しは主題に合わせて置き換える。
-->

<!-- specbind:instruction maintain
steering が担うのは、個々の変更より長く生き残る知識である。有能な新規参加者が、広く読まなければ
気づけない、あるいは一度間違えて初めて気づくような事実は、ここに属する。それより狭いものは、
それを必要とする変更の成果物に属する。

独立した文書に値することが多い主題: API 規約、テスト方針、セキュリティ方針、データと
マイグレーション、エラー処理、デプロイ。いずれも必須ではない。規約がまだ定まっていない主題は、
推測で書くより書かないほうがよい。

それ自体の目次を必要としない程度に、焦点を保つこと。
-->

## 決定と制約

<!-- specbind:instruction maintain
後続の変更が引き継ぐ確定済みの判断、禁止事項、選択基準を記載する。まだ合意されていない案や、
単一Specだけに必要な判断は含めない。決定または制約ごとに内容を表すH3見出しを付け、理由、
適用範囲、例外をその判断の近くに記載する。確定済みの内容がないなら文書自体を作成しない。
-->
