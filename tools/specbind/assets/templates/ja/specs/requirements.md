# `{{spec}}` の要件

<!-- specbind:instruction maintain
現在のマイルストーンで依頼された差分だけではなく、この Spec の現在有効な振る舞いの契約全体を
維持する。利用者またはシステムの必要性を「背景」に要約し、隣接する作業を暗黙に取り込まないよう
「スコープ」で責任境界を明示する。

各要件は `### 要件 N: 見出し` の形式の H3 見出しとし、先頭に 0 を付けない一意な正の
グループ番号を使う。グループの文書内順序に意味はなく欠番も許されるため、欠番を埋める目的で
既存グループを振り直さない。受け入れ基準は H4 見出しの下に 1 つの順序付きリストとして書く。
リストの各項目は位置によって Requirement ID N.M になるため、項目の並べ替えや削除は後続の
基準の識別子を変えてしまう。
受け入れ基準だけでは意図が伝わらない場合は、短い目的を加える。基準は観測可能な結果として書き、
有用な場合はイベント・条件・状態を明示した EARS の考え方を日本語で用いる。
実装方法そのものが要件でない限り、実装を規定しない。
-->
