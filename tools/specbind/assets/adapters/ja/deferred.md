# 保留指摘アダプタ

<!-- specbind:instruction
実在するがゲートを止める理由にはならないレビュー指摘を、このプロジェクトがどこ
に残すかを書いてください。SpecBind はこの散文を読んで従います。スクリプトでは
ありません。

このファイルがあるのは、行き先のない指摘が blocking として挙げられるからです。
放置すれば消えると分かっているレビュアには、指摘を残す手段がひとつしかなく、
実際にそれを使います。行き先を決めれば、その圧力はなくなります。

行き先は書き込む場所であって、読む場所ではありません。SpecBind が何を作るかを

に既に置き場がある場合は書き換えてください。このファイルを空にする、または削除

## 保留指摘の行き先

仕様ディレクトリ直下の `deferred.md` に追記し、ファイルがなければ作成します。
指摘ごとに1エントリを書き、どの Spec から出たかと何を危うくするかを記し、それ
以外は書き加えません。

追記の前に、同じ指摘が既に記録されていないかを確認できる範囲でだけ読み、記録済
みであれば追記しません。それ以外の目的で内容を使わないでください。

## ここに置くもの

実行可能で残す価値があり、かつ verdict を変えない観察。verdict を変える指摘は
ゲートの前に解消するものであって、ここには記録しません。

## ここに置かないもの

今回の変更が行わなければならない作業、判断を止めている未解決の問い、そして
それを生んだレビュー以外に読み手のいない覚え書き。
