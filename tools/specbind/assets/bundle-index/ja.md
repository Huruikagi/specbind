# SpecBind Knowledge Bundle

このディレクトリは、SpecBindで管理するプロジェクトのOpen Knowledge Formatバンドルです。
以下は固定の入口であり、完全な一覧ではありません。ワークフロー用のアーティファクトや
ディレクトリは、必要になったときだけ作成されます。

- [Specifications](specs/) — 現在の仕様とSpecごとのリリース履歴。
- [Steering](steering/) — プロジェクト全体の永続的な方針と進行中のMilestone。
- [Settings](settings/) — プロジェクト所有のテンプレート、Rule、運用Adapter。
