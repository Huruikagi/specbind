# SpecBind Knowledge Bundle

This directory is the project's Open Knowledge Format bundle managed with
SpecBind. These are stable entry points, not an exhaustive inventory; workflow
artifacts and directories appear only when they are needed.

- [Specifications](specs/) — current specifications and per-Spec release history.
- [Steering](steering/) — durable project-wide guidance and the active milestone.
- [Settings](settings/) — project-owned templates, rules, and operational adapters.
