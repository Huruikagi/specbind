# Parallel worktree implementation proposal

The proposal was accepted as [Decision 0201](./decisions/0201-isolated-parallel-spec-implementation.md).

The accepted scope is optional parallel implementation across independent
Specs, sequential Tasks within each Spec, and serial candidate acceptance.
Generic and other hosts without verified isolated execution continue through
the existing sequential workflow. The original exploratory proposal remains
available in Git history; the Decision and installed Skill procedure own the
current contract.
