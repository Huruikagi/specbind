# Current generated skill index

This page is a lightweight index of the skills generated by the current SpecBind CLI. It records the inherited command surface before SpecBind-specific commands and workflows are redesigned; it is not a commitment to preserve these names or behaviors.

For the files installed or maintained by these skills, see the [current generated artifact index](./current-artifact-index.md).

Both supported agents receive the same 17 skills:

- Claude Code: generated under `.claude/skills/`; invoked as `/kiro-*`
- Codex: generated under `.agents/skills/`; invoked as `$kiro-*`

| Skill | Current role |
| --- | --- |
| `kiro-debug` | Investigate implementation or verification failures. |
| `kiro-discovery` | Triage new work and decide whether and how to create specs. |
| `kiro-impl` | Implement approved tasks with TDD and subagents. |
| `kiro-review` | Review a task implementation against its spec and boundaries. |
| `kiro-spec-batch` | Generate multiple complete specs from a roadmap. |
| `kiro-spec-design` | Create the technical design for a spec. |
| `kiro-spec-init` | Initialize a new spec. |
| `kiro-spec-quick` | Generate a single spec through a shortened workflow. |
| `kiro-spec-requirements` | Create requirements for a spec. |
| `kiro-spec-status` | Report spec status and progress. |
| `kiro-spec-tasks` | Create implementation tasks for a spec. |
| `kiro-steering` | Create or update persistent project guidance. |
| `kiro-steering-custom` | Create specialized project guidance. |
| `kiro-validate-design` | Review and validate a technical design. |
| `kiro-validate-gap` | Compare requirements with an existing codebase. |
| `kiro-validate-impl` | Validate feature-level integration and spec coverage. |
| `kiro-verify-completion` | Verify completion claims with fresh evidence. |

## Sources of truth

- Skill templates: `tools/specbind/templates/agents/{claude-code-skills,codex-skills}/skills/`
- Installation manifests: `tools/specbind/templates/manifests/{claude-code-skills,codex-skills}.json`
- Agent paths and invocation syntax: `tools/specbind/src/agents/registry.ts`

When the command system changes, update this index together with the templates and manifests so it remains a useful migration checklist.
